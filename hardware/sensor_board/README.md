# Integrated Sensor Board

This folder contains the final integrated KiCad project.

```text
sensor_board/
├── sensor_board.kicad_pro
├── sensor_board.kicad_sch
├── sensor_board.kicad_pcb
├── sensor_board.kicad_dru
└── sheets/
    ├── power.kicad_sch
    ├── sensor_1.kicad_sch
    ├── sensor_2.kicad_sch
    └── interfaces.kicad_sch
```

Use hierarchical sheets for major subsystems so multiple designers can work with fewer merge conflicts.
