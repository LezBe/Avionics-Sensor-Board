## Key Package Information

Bosch specifies the BMP581 as a 2.0 mm × 2.0 mm × 0.75 mm metal-lid LGA package.

The landing-pattern section of the datasheet should be treated as the source of truth for footprint verification. Bosch recommends a land pattern with the footprint enlarged by 25 µm on each side, at least 200 µm spacing between pads, no vias or traces below the sensor, and no solder mask beneath the sensor.

## Design Note

The original BMPunit schematic uses the footprint name `QFN10_BMP581_BOS`, but the corresponding footprint file was not present in that repository. Verify any replacement footprint against Section 8.2 of the Bosch datasheet before PCB fabrication.
