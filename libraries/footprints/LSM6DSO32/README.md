# LSM6DSO32 Footprint

## Package

The LSM6DSO32 is supplied in an LGA-14 package approximately 2.5 mm × 3.0 mm × 0.86 mm.

## Official CAD Source

ST provides EDA resources from the LSM6DSO32 product page:

https://www.st.com/en/mems-and-sensors/lsm6dso32.html

The product page provides access to symbols, footprints, and 3D models through ST-supported CAD providers.

## Verification Requirements

Before committing a production footprint, verify:

- package pad count and numbering;
- pad dimensions and pitch;
- body dimensions;
- pin-1 indication;
- solder-mask and paste apertures;
- courtyard;
- assembly outline;
- sensor X/Y/Z orientation;
- footprint orientation relative to the board coordinate system.

The ST datasheet/package drawing is the source of truth.

## Manufacturing Gate

**Do not release Gerbers containing the LSM6DSO32 until the footprint and sensor orientation have been independently reviewed.**
