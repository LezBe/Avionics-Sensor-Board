# Shared KiCad Libraries

Use this area for team-maintained symbols, footprints, and 3D models.

```text
libraries/
├── symbols/
├── footprints/
└── 3d_models/
```

Before creating a custom symbol or footprint:

1. Check the official KiCad libraries.
2. Verify dimensions and pin numbering against the manufacturer datasheet.
3. Have another team member review the footprint.
