# Sensor Board Bring-Up Checklist

## Before Power

- [ ] Visual inspection completed
- [ ] Orientation of polarized components checked
- [ ] IC pin-1 orientation checked
- [ ] Solder bridges checked
- [ ] Resistance from each power rail to GND checked
- [ ] Bench supply current limit configured

## Initial Power

- [ ] Input current recorded
- [ ] Main supply rail measured
- [ ] 3.3 V rail measured
- [ ] Regulators checked for abnormal heating

## Communications

- [ ] MCU or flight-computer connection verified
- [ ] I2C devices detected
- [ ] SPI devices respond
- [ ] UART devices respond

## Sensors

- [ ] Sensor 1 basic reading verified
- [ ] Sensor 2 basic reading verified
- [ ] Sensor 3 basic reading verified

## Notes

Record anomalies, measured voltages, current consumption, and corrective actions.
